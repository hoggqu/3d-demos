## 东汐雨夜

从便利店的雨棚出发，穿过霓虹映照的积水街道，走上 HOG 站的高架站台看列车驶过。按 **WASD** 移动，用**鼠标**或**方向键**观察，按 **Shift** 快走、**T** 查看渲染统计。

单文件使用原生 WebGPU、WGSL 和 Web Audio。雨丝、车灯体积光、积水反射和店铺内景都在浏览器里生成。巡逻机器人的步态来自 Biu_Games 的 `Walk_Male`，动作采样直接内嵌在脚本里。

## 雪线

在冬季松林里踏雪。雪地会随落脚逐渐压深，拔脚时带起碎雪。按 **WASD** 移动、**Shift** 跑步，拖动视角。也可以点「自动走一段」和「近看脚印」。

## 潮闸

《潮闸》是一个第一人称的单文件 WebGPU 游戏实验。场景设在一座昏暗的海岸泵站。启动检修池的水泵，校准反光板打开卷帘门，走到栈桥上看晨光照进机房。

下载 [潮闸.html](./%E6%BD%AE%E9%97%B8.html)，用支持 WebGPU 的桌面 Chrome 或 Edge 打开。已在 Windows 的 Chrome 中通过离线验证。

- **WASD** 移动，**鼠标** 观察，**F** 开关扫灯。
- 在进门右侧的检修池边按 **E** 启动水泵，解除控制面板的联锁。
- 到黄框反光板旁按 **E** 开始校准，用鼠标或 **← / →** 调整角度。接收器充能后，卷帘门会升起。
- 按 **T** 查看渲染统计。

游戏使用原生 WebGPU 和 WGSL。几何、材质、海面和云都由代码生成，脚步、闸门和水泵音效由 Web Audio 合成。文件内包含全部运行代码和资源。

### 《潮闸》的模型与用量

开发使用 OpenAI **GPT-6.1 Sol**（`gpt-6.1-sol`），Codex 的速度档位设为 Fast（会话日志记为 `priority`）。

| 用量 | Token |
| --- | ---: |
| 缓存输入 | 111,159,424 |
| 未缓存输入 | 758,880 |
| 输出（含推理） | 365,509 |
| **合计** | **112,283,813** |

统计覆盖从讨论单文件挑战到完成水泵联锁的设计、实现和验证。首版至水泵互动用量为 108,881,063 token，随后加联锁用量为 3,402,750 token。表中的输出已包含推理 token。
